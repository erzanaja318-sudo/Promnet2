ExpoMath — Media Pembelajaran Fungsi Eksponensial Interaktif

ExpoMath adalah aplikasi web interaktif yang dikembangkan sebagai media pembelajaran mandiri untuk memahami materi perpangkatan dan fungsi eksponensial pada mata kuliah Matematika Diskrit.

Aplikasi ini dirancang untuk mempermudah pemahaman konsep secara bertahap melalui penyajian materi bentuk umum fungsi f(n) = an, penjelasan syarat basis (a > 0 dan a ≠ 1), serta kalkulator eksponensial interaktif yang menampilkan langkah perhitungan secara terperinci (dari pangkat nol, positif, hingga negatif).

Tautan Aplikasi: Buka Aplikasi ExpoMath (Live di Vercel)

Fitur Utama Aplikasi:

  • Visualisasi materi konsep dasar dan bentuk umum fungsi eksponensial
  • Penjelasan interaktif syarat basis positif dan bukan satu
  • Kalkulator eksponensial dengan uraian penyelesaian langkah demi langkah
  • Fitur contoh perhitungan cepat untuk berbagai variasi nilai basis dan eksponen
  • Antarmuka modern berbasis Single Page Application (SPA)

Teknologi yang Digunakan

  • HTML5 & CSS
  • React.js (Library Komponen UI)
  • Tailwind CSS (Styling & Tata Letak Responsif)
  • JavaScript (Logika Perhitungan Eksponensial)
  • Vercel (Infrastruktur Hosting & Deployment)
